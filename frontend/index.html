About the Project

BrainTumorAI is an academic AI project that uses a convolutional neural network to classify brain MRI images into different categories.

Key Features

MRI Classification

Upload a brain MRI image and receive an AI-based classification.

Probability Analysis

View the probability distribution across all supported classes.

Explainable AI

LIME explanations help visualize the regions influencing the model's prediction.

Important Disclaimer

This application is developed for academic and research purposes. It is not a medical diagnostic system and should not be used as a substitute for professional medical advice.
